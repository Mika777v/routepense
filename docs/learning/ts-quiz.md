## 教科書の直し候補（`main` 側の別ブランチで。このブランチではやらない）

テストで言えなかった・取り違えた点を、章に足す候補:

1. **「引いた結果は `undefined` かもしれない」を一か所にまとめる**（Q7・Q14・Q21・Q23・Q24）: `Map.get`・`find`・配列の添字を並べ、「戻り値を使う前に調べる」を共通の型で示す。`undefined` の出どころ（関数が見つけなかったとき）を、引数のせいと取り違えやすい点も書く
2. **実行時の結果を並べる**（Q23・Q24）: `200 + undefined` は `NaN`（落ちない）、`undefined.fare` は `TypeError`（落ちる）。型チェックはどちらも書いた時点で止める
3. **`throw` と `undefined` の選び方**（Q25）: `throw` は値を返さないので戻り値の型は `number` のまま。呼ぶ側のバグなら `throw`、普通にありうるなら `undefined`（戻り値は `number | undefined`）。戻り値の型だけを変えても、エラー行は消えない（Q24）
4. **`key` の挙動**（Q18・Q22）: `key={index}` で先頭を削除したとき、再利用される DOM と、最初だけ効く `defaultValue` を、画面の図で示す
