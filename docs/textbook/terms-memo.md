# 用語メモ（教科書の章を作るための下書き）

要件定義（`docs/requirements.md`）の中で出てきた用語を集めたメモです。
`docs/textbook/` の各章を書くときに、用語の初出の説明と、このプロジェクトでの実例の材料として使います。
章が完成したら、このメモの「使う章」の欄を実際のファイル名に更新します。

## TypeScript・プログラミングの用語

| 用語 | 一言の説明 | 要件の中での使われ方 | 使う章（予定） | Java との対比メモ |
|---|---|---|---|---|
| 判別可能なユニオン型 | 共通の目印（`kind`）で、どの形かを見分けられる「AまたはB」の型 | 勤務区分 `WorkStyle` = 在宅 \| 出勤 | 02-union-types | Java の sealed interface + record に近い。`switch` で網羅性を確認できる |
| リテラル型 | 特定の値だけを許す型（例: `"train"`） | 交通手段 `"train" \| "bus" \| "other"`、片道/往復 `"oneWay" \| "roundTrip"` | 02-union-types | Java の enum に近いが、値そのものが型になる |
| 型の共有（`shared/`） | フロントとバックで同じ型定義を使うこと | Route, DailyRecord などを `shared/` に置く | 01-typescript-basics（またはモジュールの章） | Java で共通の jar やモジュールを参照するイメージ |
| オプショナルなプロパティ | あってもなくてもよい項目（`purpose?: string`） | 追加の移動の目的、元ルートID | 01-typescript-basics | Java の `Optional` や null 許容の項目 |
| 配列型 | 同じ型の値の並び（`ExtraTrip[]`） | 日次記録の追加の移動 | 01-typescript-basics | Java の `List<ExtraTrip>` |
| 純粋関数 | 同じ入力なら必ず同じ結果を返し、外の状態を変えない関数 | 一括設定の対象日の計算 | 04-pure-functions-and-tests（予定） | static メソッドで副作用なし、に相当 |
| バリデーション | 入力が正しいかを確かめること | API の受け口で日付・運賃・ルートIDを確認 | API の章（予定） | Bean Validation（`@NotNull` など）に相当 |
| スナップショット | ある時点の値をコピーして保存しておくこと | 記録にルートの運賃・区間をコピーする（`RouteSnapshot`） | データ設計の章（予定） | — |
| 日付の文字列表現（YYYY-MM-DD） | タイムゾーンのずれを避けるため、日付を文字列で扱う | 日次記録の date、一括設定の期間 | 日付の扱いの章（予定） | `java.time.LocalDate` に近い考え方 |

## アプリ・業務の用語

| 用語 | 一言の説明 | 要件の中での使われ方 |
|---|---|---|
| 勤務区分 | その日が在宅か出勤かの区別 | 在宅 / 出勤（ルート付き）。休日は記録なしで表す |
| 一括登録 / 一括設定 | 期間と曜日の条件に合う日へ、同じ区分をまとめて当てはめる操作 | カレンダー画面の「一括設定」ボタン |
| 出勤ルート | 登録しておく通勤経路（出発地・到着地・交通手段・片道運賃） | 出勤日の交通費は片道運賃 × 2 |
| 追加の移動 | 通常ルートとは別に、ある日の記録に足す臨時の交通費 | 片道 / 往復を選べる。目的を書ける |
| 片道 / 往復 | 往復の金額は片道運賃 × 2 | 追加の移動で選択。出勤日は常に往復 |
| 上書き | すでにあるデータを新しい内容で置き換えること | 一括設定で既存の記録がある日 |
| ユーザーID | 記録が誰のものかを表す識別子 | 今は固定値。将来の複数ユーザーに備える |

## 開発の進め方の用語

| 用語 | 一言の説明 |
|---|---|
| MVP | Minimum Viable Product。使える最小限の機能をそろえた最初の版 |
| スコープ外 | 今回は作らないと決めた範囲 |
| 拡張性 | 将来の機能追加に、作り直しを少なく対応できる性質 |
| 外部API | ほかのサービスの機能をプログラムから呼び出す窓口（例: 経路検索） |
| 未決事項 | まだ決めていないこと。決めたら要件定義を更新する |
